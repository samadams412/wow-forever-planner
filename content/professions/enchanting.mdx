For Enchanting, there were 40 new items in total, which included both enchants and new craftable items as well as an item that unlocks a title. Some of these require new materials that don’t exist in WoW Classic such as new dyes.

## Idols

Enchanting can be used to craft some interesting Idols for the Relic slot, only usable by Druids. There seems to be one for each specialization.

## Profession Title

Each crafting profession has its own certification item that unlocks a unique title. You can only use this title if you have 300 skill in the profession.
